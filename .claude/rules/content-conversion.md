## Vietnamese → English Content Conversion


### How it works
When the user says "chuyển nội dung này sang bài viết tiếng Anh" (or similar), rewrite the provided Vietnamese content into a **native-quality English article**. This is NOT a translation — it's a full rewrite that preserves facts and data but expresses them in natural, idiomatic English.


### Writing style
- **Register**: Professional financial/investment journalism — authoritative but accessible
- **Audience**: International traders/investors (English-speaking)
- **Tone**: Informative, objective, confident. No hype, no fear-mongering
- **Voice**: Active voice preferred. Direct, clear sentences
- **Vocabulary**: Use standard financial English terminology. Avoid translation-ese ("the above", "as for", "so-called")
- **Sentence structure**: Varied length. Break long Vietnamese sentences into 2-3 shorter English ones. No run-ons
- **Cultural adaptation**: Remove Vietnam-specific references unless relevant internationally. Replace with globally recognizable context


### SEO requirements (every article)
| Element | Spec |
|---------|------|
| **Title** | H1 at top, 50-60 chars, primary keyword near front. Hook + value proposition |
| **Meta description** | 150-160 characters, includes primary keyword, call-to-action |
| **URL slug** | Hyphenated, lowercase, keyword-rich, 3-5 words |
| **H2/H3 structure** | Logical hierarchy, each section answer a question the reader would ask |
| **Keyword placement** | Primary keyword in H1, first 100 words, 1 H2, and naturally throughout |
| **Internal linking** | Where relevant, link to related pages (broker reviews, tools, guides) |
| **Image alt text** | Descriptive, keyword-inclusive for any suggested images |


### Content structure (default template)
```markdown
# SEO Title (H1, 50-60 chars)


**Meta description:** 150-160 chars.


**Excerpt:** 2-3 sentences summarizing the article (displayed on news cards).


## Introduction / Overview
- What is this about? Why should the reader care?
- 2-3 paragraphs setting context


## [Main Topic Section] (H2)
- Core content
- Sub-sections with H3 as needed


## [Another Key Section] (H2)
...


## Conclusion
- Key takeaways
- Call to action (if applicable)


*Disclaimer: This content is for informational purposes only and does not constitute financial advice. Trading cryptocurrencies, forex, and binary options carries significant risk.*
```


### Financial content disclaimers
- Every article MUST end with the standard risk disclaimer
- Binary option articles need the enhanced risk warning (high-risk, geo-restriction EU/UK/AU/CA)
- Affiliate disclosure where applicable


### What to preserve
- Facts, statistics, dates, numbers — keep exact
- Quotes (translate to natural English)
- KPIs, comparison data, review scores
- Product/brand names — keep original capitalization


### What to change/adapt
- Vietnamese sentence flow → English paragraph structure
- Vietnamese passive constructions → English active voice
- Culturally specific references → international equivalents
- Overly formal Vietnamese phrasing → natural English register


### How to invoke
Simply paste Vietnamese content or attach a file with the instruction:
> "chuyển nội dung này sang bài viết tiếng Anh"
> "chuyển file này thành bài viết tiếng Anh"
> "viết bài tiếng Anh từ nội dung này"


The system will process the content and return a complete English article following all specifications above.
